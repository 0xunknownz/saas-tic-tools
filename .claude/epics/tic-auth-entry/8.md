## What to build

按已确认的方案 2「双栏工作入口」实现 TIC 工具箱租户端登录页。桌面左侧约 42% 为浅蓝品牌介绍区，右侧为白色登录区。左侧展示 TIC工具箱、文案“检验检测工作，从这里开始。”、“连接项目、标准与报告，让团队工作井然有序。”以及项目协作、标准查阅、报告归档三个简介。右侧以“欢迎回来”为标题，提供邮箱、密码、忘记密码与登录操作。移动端收拢介绍，优先呈现表单。

复用现有 Foundation Tenant UI 认证能力及可用扩展点，提供供租户选择页复用的双栏布局；保留真实认证、MFA、安全提醒、错误重试和安全目标地址跳转，不另造认证协议。

遵循 TIC 设计规范：背景 #F8FAFC、面板白色、主色 #3B82F6、文字 #0F172A / #475569 / #64748B、边框 #E2E8F0；中文系统字体，标题 19px/800、正文 13px、控件 12px，面板/输入/按钮圆角分别为 16/12/9px。不增加注册、社交登录或未经启用的认证入口。

## Acceptance criteria

- [x] 桌面符合方案 2 的双栏布局、品牌文案与 TIC 视觉规范。
- [x] 邮箱、密码与忘记密码可操作，登录调用现有真实接口；提交期间防重复操作，失败后提示错误并支持重试。
- [x] 普通登录、MFA 验证/绑定与凭据重置后的阻塞安全提醒保持有效。
- [x] 登录及 MFA 保留安全的站内目标地址，拒绝外站跳转，不改变现有会话语义。
- [x] 小屏无页面横向溢出；标签明确，键盘可完成操作，焦点清晰可见，错误提示可被辅助技术识别。
- [x] 完成桌面、移动端视觉检查，通过类型检查与相关登录、认证路由回归测试。
- [x] 双栏布局可供租户选择页复用，样式不影响其他认证页或管理端。
