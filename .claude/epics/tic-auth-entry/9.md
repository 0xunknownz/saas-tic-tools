## What to build

按已确认的方案 2「双栏工作入口」实现 TIC 工具箱租户选择页，复用登录页的双栏布局与品牌介绍。右侧以“选择租户”为标题、“选择组织，进入对应工作空间”为说明，展示当前账号与所属租户。

租户呈现为一个分隔线列表，每行展示组织名称、角色及“进入”操作，突出当前租户；点击每行入口直接调用现有会话切换接口，不增加先选中再确认的步骤。组织、角色、当前租户均来自真实会话与成员关系列表。文案“使用其他账号”仅在真实退出或切换账号流程成立时提供，不得只跳转登录页而保留原会话，退出失败不得伪造成功。

沿用 TIC 视觉规范与既有 Foundation Tenant UI 能力，保留加载、空列表、失败重试以及成员关系列表接口不可用时的手动输入回退。成功后进入安全目标地址，未指定时进入工作台。不新增后台接口、数据库结构、租户创建或搜索筛选功能。

## Acceptance criteria

- [x] 桌面与登录页共享方案 2 双栏布局；列表使用分隔线、克制的浅蓝当前租户高亮与逐行“进入”按钮，符合 TIC 字体、颜色与圆角规范。
- [x] 使用现有接口获取真实成员关系，显示组织名称、角色和当前租户，不用示例组织冒充真实数据。
- [x] 点击“进入”调用真实租户会话切换接口；请求期间防重复操作，失败后保留页面并显示可重试错误，成功后导航。
- [x] 保留安全站内目标地址；会话失效转登录时保留该目标，拒绝外站跳转。
- [x] 加载、无租户、加载失败重试与现有接口不可用时的手动输入回退均可验证。
- [x] “使用其他账号”完成真实账号退出或切换流程，错误可见，不伪造退出成功。
- [x] 小屏布局无页面横向溢出，长组织名称可读；进入操作有明确可访问名称，键盘焦点与状态提示可识别。
- [x] 完成桌面、移动端视觉检查，通过类型检查与相关租户切换、认证路由回归测试，验证从登录到切换租户及返回目标页面的完整路径。
