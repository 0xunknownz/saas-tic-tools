## What to build

按已选第 3 组「轻量设置」实现 TIC 工具箱租户端成员管理页。管理员进入 /console/members，查看真实成员，通过右上角“邀请成员”打开右侧侧栏，通过成员行内“管理”菜单执行已有账号安全操作。

同时交付账单页可复用的租户管理布局：72px 一级栏、232px 二级栏、58px 顶栏，内容内边距 16px 22px 28px；二级导航包含成员管理、账单管理、返回工作台。页面标题“成员管理”，说明“管理成员访问权限与账号安全。”；主体为成员、邮箱、角色、MFA、加入时间及操作表格。桌面邀请侧栏约 360px，提供邮箱、发送邀请、手动邀请和关闭操作。

复用 Foundation Tenant UI 公开 hook/API 及扩展点，保留邮件邀请、手动邀请、角色管理能力及限制、MFA 重置、发送密码重置、移除成员的真实协议和安全保护。凭据重置保留原因校验，危险操作仍需确认。角色仅使用接口支持的 tenant_admin / member，不增加角色提升能力，不修改依赖包产物或复制认证协议。

视觉遵循 TIC 规范：背景 #F8FAFC、白色面板、主色 #3B82F6、文字 #0F172A / #475569 / #64748B、边框 #E2E8F0；中文系统字体；标题 19px/800、面板标题 15px/800、正文与表格 13px、控件 12px；面板/输入/导航/按钮圆角 16/12/10/9px。补充相关页面规范，明确本任务扩展此前“不修改管理端样式”的范围，仅覆盖租户管理端。

图中示例成员及“示例数据”横幅不进入真实管理页面；示例仅用于测试或明确标记的独立预览。不新增接口、数据库结构、搜索、筛选或分页，不改平台管理端和认证页。

## Acceptance criteria

- [x] 直接访问、刷新及前进后退正常，工作台入口、成员/账单导航与返回工作台保持正确的跨应用跳转。
- [x] 页面符合方案 3 的表格、管理菜单、右侧邀请侧栏及 TIC 规范；布局可供账单页复用，文档与实现一致。
- [x] 成员、角色、MFA 和加入时间来自真实接口；加入时间延续 UTC 标注，当前账号有标识，保留自身操作限制、角色权限判断和不支持角色提升的说明。
- [x] 邀请侧栏可打开/关闭；邮箱必填及格式错误关联字段；邮件邀请和手动邀请调用各自真实接口，提交中防重复，失败保留输入并支持重试，不将请求受理表述为邮件已送达。
- [x] 手动邀请及重置凭据按既有协议展示，不持久化或写日志；重新打开侧栏不意外暴露上一轮凭据。
- [x] MFA 重置、发送密码重置和移除可完成；危险操作确认、原因校验、取消不提交、错误提示和提交中保护有效，成功后按真实响应更新状态。
- [x] 会话加载、错误重试、登录及租户选择跳转、无权限保护有效；加载、空列表和接口错误有明确反馈，不使用假成功或示例数据替代真实结果。
- [x] 小于 1000px 导航自适应，390px 页面无横向溢出，表格只在自身容器内滚动；侧栏有可访问名称、焦点进入/约束/恢复及 Escape 关闭，菜单可键盘操作，焦点和状态反馈可识别。
- [x] 完成桌面/移动端视觉对照，通过类型检查、构建及相关导航/权限回归；最小有效测试覆盖邀请校验、失败重试、侧栏键盘行为及危险操作确认。
- [x] 样式限定在租户管理端，不影响认证页或平台管理端。
