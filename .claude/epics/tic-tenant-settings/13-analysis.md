# 实施与验收分解

依赖 #12 的共用布局。使用公开 useBilling，按订阅 snapshot 展示整数分金额与周期，按目录 prices 将每个购买按钮对应到 planCode / interval / currency。订阅状态取服务端，不从套餐名推断。取消复用服务端 pending 立即结束与已付周期到期取消语义。

验收覆盖价格字段对应、缺失周期/有效期、provider=none、失败重试、防重复、取消后刷新失败与真实状态更新；复用权限与导航回归，完成桌面与390px视觉对照。现有真实服务未配置支付提供方，购买参数与失败分支以公开API stub测试；真实接口覆盖禁用购买及实际取消。
