## What to build

按已选第 3 组「轻量设置」实现 TIC 工具箱租户端账单管理页。管理员进入 /console/billing 查看真实当前订阅、对比可用套餐，按月付/年付购买套餐，并使用现有取消订阅能力。复用成员管理任务提供的租户管理布局与导航。

标题“账单管理”，说明“管理当前订阅与套餐。”。上方为横向订阅摘要，展示套餐、状态、金额/币种/计费周期、有效期和克制的取消订阅操作；按真实状态解释取消后的生效时间和可用期限。下方为“可用套餐”对比表，展示套餐、功能与额度、月付和年付价格及购买动作，突出当前套餐。金额、周期、功能、额度和状态均取自真实响应，不硬编码图中的示例数值，不用仅比较套餐名称推断完整订阅状态。

复用 Foundation Tenant UI 公开 hook/API 及可用扩展点，保留现有购买、取消、重试、支付提供方未配置时的限制及安全导航，不修改依赖包产物，不新增支付协议。复用项目既有金额表示，以接口整数分值进行正确展示，不引入金额计算抽象。

沿用 TIC 规范：背景 #F8FAFC、白色面板、主色 #3B82F6、文字 #0F172A / #475569 / #64748B、边框 #E2E8F0；中文系统字体；标题 19px/800、面板标题 15px/800、正文与表格 13px、控件 12px；面板/输入/导航/按钮圆角 16/12/10/9px。补充对应页面规范及验收记录。

真实管理页面不保留设计图中的示例数据横幅。不新增发票、账单流水、支付方式管理、折扣、用量图表、后台接口或数据库结构，不修改平台管理端与其他认证页。

## Acceptance criteria

- [x] /console/billing 可直接访问、刷新及前进后退；导航正确高亮，成员管理与工作台往返正常，复用现有会话及管理权限保护。
- [x] 符合方案 3 的订阅摘要与套餐对比表，以及 TIC 字体、颜色、圆角和布局规范；相关文档与实现一致。
- [x] 套餐、状态、价格/币种/周期、有效期、功能与额度来自真实接口；无订阅、无套餐、缺失有效期时有合理展示，不硬编码示例金额或虚构账单。
- [x] 月付/年付分别提交对应套餐、周期及币种；只展示接口提供的价格，购买期间防重复；失败显示可重试错误，成功或跳转按既有支付协议处理，不把创建购买请求表述为已支付。
- [x] 取消订阅仅在真实允许的状态可用，保留既有取消语义与风险说明；进行中防重复，失败不伪造成功，成功后刷新订阅并按真实状态展示到期取消及可用期限。
- [x] 支付提供方未配置时明确说明且禁用购买，保留已有可用行为；加载、加载失败重试及购买/取消错误状态清晰可识别。
- [x] 小于 1000px 布局自适应，390px 页面无横向溢出；套餐表只在自身容器内滚动，价格与购买操作保持对应，可键盘操作，焦点和状态提示可识别。
- [x] 完成桌面/移动端视觉对照，通过类型检查、构建和相关导航/权限回归；最小有效测试覆盖价格与购买参数对应、未配置支付、购买失败及取消状态更新。
- [x] 样式仅作用于租户管理端，不破坏成员页、认证页或平台管理端。
