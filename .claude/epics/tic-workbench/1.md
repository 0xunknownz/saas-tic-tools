## What to build

让用户通过现有登录流程进入 TIC 工作台首页，并能通过完整导航访问稳定 URL。将原型视觉规则写入项目设计规范，同时交付可运行的首页和公共布局，供后续页面复用。组件先在 Web 应用内复用，不提取跨应用共享包。

参考原型：http://localhost:5173/。原型仅作为页面与视觉参考，不迁移其 bearer-token 登录、旧报告角色分支或业务 API 客户端。若原型无法访问，以下已确认参数和范围仍作为实现依据，并在验证记录中说明缺少视觉对照。

视觉基线：72px 一级图标栏、232px 二级栏、58px 顶栏；内容内边距 16px 22px 28px；背景 #F8FAFC、白色面板、主色 #3B82F6、文字 #0F172A / #475569 / #64748B、边框 #E2E8F0；系统中文字体；页面标题 19px/800、面板标题 15px/800、正文及表格 13px、控件 12px；面板/输入框/导航项/按钮圆角分别为 16/12/10/9px；延续原型图标风格。小于 1000px 时使用单列和可用的窄屏导航。

完整导航保留：工具首页、公司公告；项目中心下的项目库、项目溯源、投标登记、采购意向、质疑与投诉、结果归档；数据工具中心下的真实查询、检测机构、资质查询、资质证书、国家标准、法律法规、技术参数与评分标准、投诉案例、专家、投标单位、中标单位（最后一项为原型中的组合入口）；检测报告数字档案库；运营与管理及其原型子菜单；资质授权与联系我们。五个重点页面以外的入口先使用通用列表或说明页，明确显示模板状态，不制造虚假业务成功反馈。

首页提供与原型一致的信息层级和工具、项目快捷入口，使用本地示例数据。保留现有租户管理端和平台管理端的入口与职责。

## Acceptance criteria

- [x] 登录后能进入工作台首页；首页快捷入口与导航到达一致的目标页面。
- [x] 每个业务入口有真实 URL；刷新、直接访问、前进后退保持页面与导航选中状态一致；未知路径有可理解的反馈。
- [x] 登录、租户选择、找回密码、重置密码、邀请接受、MFA 注册与验证沿用现有流程；保留安全 redirect、token 参数及现有认证约束，不新增原型登录弹窗。
- [x] 成员及账单入口继续跳转到现有租户管理端；不替换两个管理端的页面或样式体系。
- [x] 项目设计规范覆盖视觉参数、布局、组件状态、响应式、路由与示例数据约定，并明确五个重点页面及其他模板入口边界。
- [x] 初始布局组件及非重点入口可独立演示；所有导航均可操作，没有静默失效按钮。

- [x] 沿用 TIC 原型的视觉规则，复用工作台现有组件；补充本页对应的项目设计规范，保持文档与实现一致。
- [x] 桌面端及小于 1000px 的窄屏可用；表格在自身容器内横向滚动，表单、导航、详情与键盘焦点可访问。
- [x] 示例数据明确标识；本地数据变动提示刷新重置，不发送真实业务写请求，不模拟授权成功或真实文件上传成功。
- [x] 通过相关类型检查、构建和针对非平凡交互的最小有效测试，并完成对应页面的浏览器交互检查。
