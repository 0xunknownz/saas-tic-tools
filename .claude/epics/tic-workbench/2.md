## What to build

用户从工作台进入公司公告，以本地示例数据完成公告查找和全文阅读。交付公告列表、关键词筛选、分页、详情和无结果状态；详情采用稳定路由，刷新和返回列表均正常。补充内容列表与详情页的设计规范。

## Acceptance criteria

- [ ] 从导航进入公告列表，可见清晰的标题、发布日期和阅读入口。
- [ ] 关键词筛选实际影响结果；改变筛选条件重置分页，分页只展示当前结果集，清空筛选可恢复列表。
- [ ] 点击公告进入对应详情，标题、时间与正文和所选记录一致；直接访问详情及刷新可用，返回列表路径明确。
- [ ] 无匹配结果和不存在的公告都有明确反馈；没有空白页或误显示其他记录。

- [ ] 沿用 TIC 原型的视觉规则，复用工作台现有组件；补充本页对应的项目设计规范，保持文档与实现一致。
- [ ] 桌面端及小于 1000px 的窄屏可用；表格在自身容器内横向滚动，表单、导航、详情与键盘焦点可访问。
- [ ] 示例数据明确标识；本地数据变动提示刷新重置，不发送真实业务写请求，不模拟授权成功或真实文件上传成功。
- [ ] 通过相关类型检查、构建和针对非平凡交互的最小有效测试，并完成对应页面的浏览器交互检查。
