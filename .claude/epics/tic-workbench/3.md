## What to build

用户通过项目库查找和查看项目，并体验完整的本地新建项目流程。交付关键词与地区筛选、分页、项目详情、新建表单和输入校验。新建项目在当前页面会话内进入列表并可查看，刷新后恢复示例数据；不调用真实项目接口，不增加附件上传、审核或复杂项目管理功能。补充业务列表、详情和表单的设计规范。

## Acceptance criteria

- [x] 从项目中心进入项目库，关键词与地区筛选可组合使用，分页与结果计数一致，切换筛选后重置分页。
- [x] 可查看选中项目的详情；固定示例项目支持直接访问与刷新，不存在的项目有明确反馈。
- [x] 新建项目表单明确标注必填项，校验空白及无效输入；取消不创建记录，提交有效数据后在本地列表可见并能打开详情。
- [x] 页面明确提示新增数据仅保存在当前会话、刷新重置；刷新后访问已消失的本地记录有可理解的反馈。
- [x] 无结果状态、表单错误反馈和重复点击提交的行为可验证。

- [x] 沿用 TIC 原型的视觉规则，复用工作台现有组件；补充本页对应的项目设计规范，保持文档与实现一致。
- [x] 桌面端及小于 1000px 的窄屏可用；表格在自身容器内横向滚动，表单、导航、详情与键盘焦点可访问。
- [x] 示例数据明确标识；本地数据变动提示刷新重置，不发送真实业务写请求，不模拟授权成功或真实文件上传成功。
- [x] 通过相关类型检查、构建和针对非平凡交互的最小有效测试，并完成对应页面的浏览器交互检查。
