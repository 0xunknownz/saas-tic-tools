## What to build

用户从数据工具中心进入国家标准查询，以关键词和分类定位本地示例标准，并查看对应标准信息。交付查询、分类筛选、重置、分页、详情与空状态，补充查询页及筛选组件规范。不接入外部标准数据库，不伪造标准全文下载能力。

## Acceptance criteria

- [ ] 国家标准入口显示标注为示例的标准编号、名称、分类与状态，列表与详情数据一致。
- [ ] 关键词与分类筛选可组合使用；查询、重置和分页实际生效，结果计数正确且筛选变更不会滞留无效页码。
- [ ] 点击结果进入对应详情；稳定示例记录可通过 URL 直接打开与刷新，返回查询页路径明确。
- [ ] 无结果和不存在的标准都有明确反馈；不展示无法使用的下载按钮或虚假下载成功信息。

- [ ] 沿用 TIC 原型的视觉规则，复用工作台现有组件；补充本页对应的项目设计规范，保持文档与实现一致。
- [ ] 桌面端及小于 1000px 的窄屏可用；表格在自身容器内横向滚动，表单、导航、详情与键盘焦点可访问。
- [ ] 示例数据明确标识；本地数据变动提示刷新重置，不发送真实业务写请求，不模拟授权成功或真实文件上传成功。
- [ ] 通过相关类型检查、构建和针对非平凡交互的最小有效测试，并完成对应页面的浏览器交互检查。
