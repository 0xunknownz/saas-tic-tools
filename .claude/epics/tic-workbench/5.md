## What to build

用户进入检测报告数字档案库，使用本地示例数据筛选报告、分页浏览并查看报告档案和附件信息。交付适合模板演示的报告列表与详情，不迁入原型的真实 API 切换、旧角色演示或上传流程。补充档案页面与附件展示规范。

## Acceptance criteria

- [x] 档案入口提供报告编号、名称或关联对象、日期与状态等清晰信息，示例报告及附件均有明确标识。
- [x] 关键词和状态筛选、重置、分页实际影响结果；计数正确，筛选变更后重置分页，支持无结果状态。
- [x] 点击报告可查看对应档案和附件元信息；详情支持直接访问、刷新与返回，未知档案有明确反馈。
- [x] 没有真实上传或下载承诺；未提供可用示例文件时只展示附件信息，不出现虚假操作成功反馈。
- [x] 列表、详情及附件信息在窄屏仍可阅读和操作，保持报告数据与当前选择一致。

- [x] 沿用 TIC 原型的视觉规则，复用工作台现有组件；补充本页对应的项目设计规范，保持文档与实现一致。
- [x] 桌面端及小于 1000px 的窄屏可用；表格在自身容器内横向滚动，表单、导航、详情与键盘焦点可访问。
- [x] 示例数据明确标识；本地数据变动提示刷新重置，不发送真实业务写请求，不模拟授权成功或真实文件上传成功。
- [x] 通过相关类型检查、构建和针对非平凡交互的最小有效测试，并完成对应页面的浏览器交互检查。
