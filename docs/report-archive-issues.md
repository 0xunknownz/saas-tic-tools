## 1. [报告档案] 租户档案数据与读取权限

建立报告、原件关联、明细、处理记录和修订版本的数据契约，交付真实报告列表与详情读取路径，供后续上传接入。

依赖：无，可开始。

权限和边界以 PRD 权限矩阵为准。本任务包含对应数据、API、界面及验证，已有能力优先复用。

### 验收标准

- [ ] 服务端可信租户上下文贯穿报告、明细、原件、OCR 文本和任务；两个租户交叉访问均失败且无数据泄漏
- [ ] 成员和管理员可读取本租户档案；成员管理操作被拒绝；平台角色不会自动获得报告读取权限
- [ ] 移除成员后旧会话、文件链接与任务 ID 不能继续读取；切换租户清除旧数据并丢弃旧请求响应
- [ ] 模型区分检测结论与归档状态，记录创建人、时间、原件摘要、解析运行及规则版本
- [ ] 沿用现有认证、MFA、租户上下文和存储能力，完成数据库迁移、API、页面及真实权限集成验证

## 2. [报告档案] PDF 批量上传、校验与并发去重

成员批量上传，逐份查看结果；成功接收的 PDF 关联档案并可靠入队。

依赖：任务 1。

权限和边界以 PRD 权限矩阵为准。本任务包含对应数据、API、界面及验证，已有能力优先复用。

### 验收标准

- [ ] 一次最多 50 份，单份最多 50,000,000 字节和 100 个物理页；精确边界与超限测试通过
- [ ] 服务端验证实际 PDF 类型和可读性；扫描 PDF、无需密码可读的权限加密 PDF 可接收；密码、损坏、非 PDF、超限逐份说明原因
- [ ] 一份失败不影响其他文件，成员可重试自己的上传失败文件；成功接收后关闭页面不丢任务
- [ ] 同租户文件摘要去重覆盖并发上传、重复提交和处理中记录，不产生重复档案或有效任务；不同租户独立处理
- [ ] 重复文件链接现有档案，已作废重复进入管理员处理；失败不产生可见空档案，文件保存与业务写入失败可恢复
- [ ] 上传页面显示逐份进度、结果和汇总，服务端限制绕过前端仍有效

## 3. [报告档案] 云端 OCR 联调与可靠任务处理

上传成功自动执行云端 OCR，保存全文、页码及原始结果，用户重新进入页面可以看到处理进度。

依赖：任务 2。

权限和边界以 PRD 权限矩阵为准。本任务包含对应数据、API、界面及验证，已有能力优先复用。

### 验收标准

- [ ] 使用授权样本实测选择供应商，记录 API/模型版本、识别差异、耗时、费用与供应商限制，凭据只保留在服务端
- [ ] 暂时性故障最多自动重试 3 次，不包含首次调用，退避执行；上限后待处理；管理员可在处理原因后手动重试
- [ ] 超时、限流、进程崩溃和重启后有可验证恢复路径，重复执行无重复档案且不覆盖人工结果

- [ ] 界面持久展示待 OCR、OCR 中及失败原因；阶段错误与规则不匹配区分
- [ ] 保留原始 OCR、全文与物理页码；报告内容仅作数据，外部返回校验且无任意脚本执行；每份完整处理不静默截页

## 4. [报告档案] 模板规则管理与跨页明细结构化

平台维护内置模板，租户管理员配置本租户规则，先试解析再启用，并基于首套报告版式提取完整资料和明细。

依赖：任务 3。

权限和边界以 PRD 权限矩阵为准。本任务包含对应数据、API、界面及验证，已有能力优先复用。

### 验收标准

- [ ] 规则包含机构与版式匹配、提取、空值、必填、格式和明细完整性校验；仅允许受约束配置
- [ ] 草稿、试解析、启用与版本可追溯；试解析不修改归档；租户规则不影响其他租户；多匹配/无匹配待处理
- [ ] 报告编号、产品名称、机构、委托单位、日期、结论必填；受检单位、生产单位、型号、类别、依据和备注按模板解析；报告名称由产品名称生成
- [ ] 报告日期来自正确正文语义，不以抽样日期、上传日期或 PDF 创建日期代替；分包机构/编号不覆盖主报告字段
- [ ] 明细保存大项、子项、技术要求、单位、方法、结果原文、单项判定、顺序、来源页码；合并单元格继承和跨页延续正确
- [ ] 首套样本 34 种增塑剂逐项保存；多技术要求不丢行；未检出、检出限、比较符号、空白及 / 保留语义
- [ ] 完整预期字段/明细逐项比对，漏行、错列、重复行和归属错误被检测或转待处理；独立同版式样本验证

## 5. [报告档案] 自动归档、人工复核与版本追溯

解析后校验归档，管理员在 PDF 原件旁处理异常、编辑资料及明细、确认修订关系或作废恢复。

依赖：任务 4。

权限和边界以 PRD 权限矩阵为准。本任务包含对应数据、API、界面及验证，已有能力优先复用。

### 验收标准

- [ ] 必填、格式、完整性、一致性及重复冲突校验通过才自动归档；报告不合格结论可正常归档
- [ ] 异常展示阶段和原因；管理员可对照预览补齐并逐项确认完整性、填写原因人工归档，必填/格式校验仍必须通过
- [ ] 原件预览可定位来源物理页，所有预览请求遵守租户权限；编辑支持基本资料和明细
- [ ] 同机构同编号不同内容进入待处理；确认修订关系、指定当前有效版并保留旧版；并发确认不能产生多个当前版
- [ ] 作废填写原因；错误原件作废重传；相同文件已作废时管理员可恢复并留痕
- [ ] 规则更新不改写历史；重解析生成候选，管理员确认替换；保留人工改动、解析版本和前后值
- [ ] 多人编辑检查版本冲突；所有修正、人工归档、规则启用、重试、作废、恢复及修订确认记录操作者、时间和原因

## 6. [报告档案] 真实档案查询、明细筛选与下载

用户查找当前有效报告，查看结构化资料、明细、原件以及历史版本，下载本租户原件。

依赖：任务 5。

权限和边界以 PRD 权限矩阵为准。本任务包含对应数据、API、界面及验证，已有能力优先复用。

### 验收标准

- [ ] 关键词覆盖编号、产品、检测机构、委托单位、受检单位；支持报告日期、处理状态、检测项目名称、单项判定筛选
- [ ] 项目名称和判定须命中同一子项；交叉明细分别命中的反例不返回；报告去重、分页和计数一致
- [ ] 默认当前有效报告，可明确筛选待处理、历史、作废；详情标明状态和版本关系
- [ ] 列表、详情、全文/OCR内容、预览和下载均服务端校验租户及成员资格；过期身份无法绕过
- [ ] 支持直接 URL、刷新、返回、未知档案、加载失败与重试；窄屏、键盘和空状态可用
- [ ] 原件保持不变，下载文件与对应档案一致；真实数据替代报告示例页面并保持现有导航
