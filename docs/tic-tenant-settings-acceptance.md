## 验收方法与范围

使用既有 Web http://localhost:13000、同域租户后台 /console/ 与既有真实 API http://localhost:18080，不替换运行服务。Playwright Chromium，桌面 1440×960，移动端 390×844。真实流程未拦截或伪造会话、成员、邀请、角色、安全操作和账单读取/取消接口。

通过 Foundation 领域服务创建专用租户、三名专用账号及两项专用套餐。订阅由 Foundation test 支付提供方的购买和已付事件建立，随后由现有服务真实读取与取消。现有服务 provider=none，浏览器实际验收购买禁用；月付/年付参数、不同币种、失败重试和重复提交通过公开 TenantApiProvider 下的真实 hook + API stub 测试验证。本报告不将这些 stub 结果表述为生产支付或外部支付提供方联调。

## 验收中修复的导航问题

租户路由的内部 pathname 不含 /console，最初用它生成切换租户的返回地址会丢失应用前缀。最终实现订阅路由位置变化，使用含 /console 的完整 href（含 query/hash）生成返回参数；新增布局集成测试同时覆盖应用内跳转与历史返回，防止地址停留在上一页。
